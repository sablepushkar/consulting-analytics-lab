# How I want to work through a case

My intended process is simple:

1. Write down the question before opening a spreadsheet or writing code.
2. List the data I have and the information I still need.
3. Check units, missing values, duplicates and obvious errors.
4. Define each metric and calculate a baseline.
5. Compare a few scenarios by changing one or two assumptions at a time.
6. Check important calculations by hand or with a small test.
7. Write the finding in plain language and state what would change my conclusion.

The main limitation at the moment is that only the basic metric functions and one small synthetic profitability example have been added. The market-entry, operational-efficiency and public-data cases are still outlines. I will update this page as the work becomes real rather than describing planned features as completed.
