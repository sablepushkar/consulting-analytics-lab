# Profitability example

I am using fictional values for the first calculation check: selling price ₹120 per unit, variable cost ₹75 per unit and fixed costs of ₹1,000.

The contribution per unit is ₹45. Break-even volume is the fixed cost divided by contribution per unit, rounded up to a whole unit. The numbers are intentionally small so I can check the answer by hand.

This example does not include tax, discounts, returns, capacity limits or changes in price and cost. Those would need to be considered in a more realistic case.
