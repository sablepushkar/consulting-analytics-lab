# Public-data case — how I will approach it

I have not chosen the final dataset yet. I want to select one with a clear source and documentation rather than download a large file just to make charts.

Before analysing it, I will record:

- Who published it and where the original file can be found.
- When I downloaded it and what period it covers.
- The meaning and units of the columns I use.
- Missing values, duplicates and any rows I exclude.
- The exact calculations I make.
- What the data can show and what it cannot show.

I will keep the original file unchanged where possible and put any cleaning steps in code. If the dataset is observational, I will not treat a relationship between two variables as proof that one caused the other.
